## BLACK PC v1.1.1

### Español

**Corrección**
- **NO RELOAD** no funcionaba con algunas armas, como el WA 2000: el cargador seguía vaciándose y pedía recargar. Ahora funciona con todas las armas que se probaron (incluido el WA 2000).

**Instalar:** descarga `BLACK-PC-Setup.exe`, ejecútalo y elige el `.iso` de tu copia (USA o Europa). El juego no se incluye. `BLACK-PC.zip` es lo mismo sin instalador. Si ya tienes una versión instalada, basta con ejecutar el instalador nuevo.

**Limitaciones y lo no validado:** como en [v1.1.0](https://github.com/zetacean/BLACK-PC/releases/tag/v1.1.0). Además, la casilla de silenciador se intentó y se descartó: el juego solo cambia el modelo y no el sonido ni la alerta de los enemigos, y no se encontró el campo que indica que llevas uno.

### English

**Fix**
- **NO RELOAD** did not work with some weapons, such as the WA 2000: the magazine kept emptying and asked for a reload. It now works with every weapon tested (WA 2000 included).

**Install:** download `BLACK-PC-Setup.exe`, run it and pick the `.iso` of your own copy (USA or Europe). The game is not included. `BLACK-PC.zip` is the same without an installer. If a version is already installed, just run the new installer.

**Known limits and what was not validated:** as in [v1.1.0](https://github.com/zetacean/BLACK-PC/releases/tag/v1.1.0). Also, a silencer checkbox was tried and dropped: setting the game's field only changes the model, not the sound or enemy alerting, and the field for carrying one was not found.
