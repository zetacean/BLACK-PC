## BLACK PC v1.0.1

### Español

**Corrección importante.** En v1.0.0, después de instalar con `BLACK-PC-Setup.exe`, el juego podía mostrar «The compiler folder is missing files. Extract the whole release again…» y no arrancar. Les pasaba a quienes tienen la zona horaria por detrás de UTC (América, por ejemplo): las fechas de los archivos instalados quedaban en el futuro y el juego creía que su código estaba desactualizado, pero el instalador ya había borrado las herramientas para recompilarlo.

**Qué cambió**
- El instalador ya no depende de las fechas de los archivos: `BLACK.exe` guarda junto a `Black.dll` una marca (`Black.stamp`) que sobrevive al borrado de la carpeta `compiler`.
- El instalador aplica las fechas en UTC.
- Mejoras internas del workflow de release.

**Si instalaste v1.0.0:** desinstala y vuelve a instalar con `BLACK-PC-Setup.exe` de esta versión.

**Instalar:** descarga `BLACK-PC-Setup.exe`, ejecútalo y elige el `.iso` de tu copia (USA o Europa). El juego no se incluye. `BLACK-PC.zip` es lo mismo sin instalador.

Limitaciones y lo no validado: igual que en [v1.0.0](https://github.com/zetacean/BLACK-PC/releases/tag/v1.0.0) (gyro con mando real, una partida completa, traducciones del instalador sin revisión nativa, instalador sin firmar).

### English

**Important fix.** In v1.0.0, after installing with `BLACK-PC-Setup.exe`, the game could show "The compiler folder is missing files. Extract the whole release again…" and not start. It hit users whose time zone is behind UTC (the Americas, for example): the installed files' dates ended up in the future, so the game thought its code was out of date, but the installer had already deleted the tools needed to rebuild it.

**What changed**
- The installer no longer relies on file dates: `BLACK.exe` keeps a stamp (`Black.stamp`) beside `Black.dll` that survives deleting the `compiler` folder.
- The installer applies file dates in UTC.
- Internal release-workflow improvements.

**If you installed v1.0.0:** uninstall and reinstall with this version's `BLACK-PC-Setup.exe`.

**Install:** download `BLACK-PC-Setup.exe`, run it and pick the `.iso` of your own copy (USA or Europe). The game is not included. `BLACK-PC.zip` is the same without an installer.

Known limits and what was not validated: as in [v1.0.0](https://github.com/zetacean/BLACK-PC/releases/tag/v1.0.0) (gyro on a real pad, a full playthrough, installer translations without native review, unsigned installer).
